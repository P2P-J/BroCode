# BroCode 기획서

> 버전 0.1 · 2026-11-09 · 상태: v0.1.0 구현 완료

## 1. 제품 이름

| 구분 | 값 |
|---|---|
| 정식 이름 (ko) | **강호의도리 (동영상 건너뛰기 · 방향키 10초 이동 · 재생바 그라데이션 제거 · 볼륨 단축키)** |
| 정식 이름 (en) | **BroCode (Video Skip Hotkeys, Remove Player Gradient, Hide Controls)** |
| 짧은 이름 | BroCode (en) / 강호의도리 (ko) |
| 스토어 설명 (ko) | 어떤 동영상 사이트에서도 방향키로 건너뛰기·되감기, 위아래로 볼륨, 스페이스바로 재생/정지. 재생바 검은 그라데이션과 hover 컨트롤바를 없애 영상을 깨끗하게 봅니다. |
| 스토어 설명 (en) | Arrow-key skip & rewind, volume and space-to-pause on any video site. Removes the dark player gradient and hover controls for a clean view. |

- Chrome 확장 `name`은 최대 75자이다. 위 두 이름은 각각 53자, 67자로 제한 안에 들어간다.
- 괄호 안 문구는 사용자가 실제로 검색할 법한 표현으로 정했다. 예: "동영상 건너뛰기", "방향키 10초", "재생바 그라데이션 제거", "볼륨 단축키", "skip", "hide controls".

## 2. 배경과 문제
- 대부분의 동영상 플레이어는 ←/→ 건너뛰기, ↑/↓ 볼륨, Space 재생/정지를 지원한다. 그런데 일부 사이트는 아래 중 하나에 해당한다.
  - 단축키가 아예 없다.
  - 재생바를 직접 클릭해야만 키가 먹는다. 영상 화면을 클릭하면 동작하지 않는다.
  - 건너뛰기를 의도적으로 막아두었다.
  - 이동 간격이 사이트마다 제각각이다(5초, 10초 등).
- 재생바 뒤 검은 그라데이션, 마우스를 올리면 뜨는 컨트롤바·썸네일·툴팁이 영상을 가린다.

## 3. 목표
1. 웬만한 모든 웹 동영상 플레이어에서 **같은 키로 같은 동작**을 하게 한다.
2. 사이트가 원래 가진 다른 단축키(M 음소거, C 자막, F 전체화면 등)는 **그대로 살린다**.
3. 영상을 가리는 UI 효과를 없애되, 자막과 영상 자체(레터박스 포함)는 건드리지 않는다.
4. 설정은 한 번 정하면 계속 유지한다. 영어와 한국어를 지원한다.

### 비목표
- DRM이나 서버 제한 때문에 데이터가 없는 구간으로 이동하는 것
- 광고 차단, 영상 다운로드

## 4. 기능 명세

### 4.1 기능 A — 단축키 강제 (Hotkeys)

| 키 | 동작 |
|---|---|
| → | 앞으로 N초 (누르고 있으면 키 반복마다 계속 이동) |
| ← | 뒤로 N초 (누르고 있으면 계속 이동) |
| ↑ | 볼륨 +5% (음소거면 해제) |
| ↓ | 볼륨 −5% |
| Space | 재생 / 일시정지 |
| 그 외 모든 키 | 사이트 기본 동작 그대로 |

**이동 간격 모드**

| 모드 | 이름 | 규칙 |
|---|---|---|
| 1 | 자동 (영상 길이 기반) | 20분 미만 10초 · 20~60분 15초 · 60분 이상 30초 · 라이브 10초 |
| 2 | 고정 평균값 | 앞/뒤 항상 15초 |
| 3 | 직접 지정 | 앞/뒤를 따로 입력. 기본값 10초/10초, 범위 1~600초 |

**동작 규칙**
- 페이지 어디를 클릭했든 동작한다(영상 화면, 재생바, 빈 공간).
- 다음 경우에는 키를 가로채지 않는다.
  - 검색창, 댓글창 같은 입력칸에 커서가 있을 때
  - 한글 입력 조합 중일 때
  - Ctrl/Alt/Cmd 조합 키일 때
- Space는 영상이 화면에 보일 때만 재생/정지로 쓴다. 영상이 없으면 평소처럼 스크롤된다.
- 화면에 영상이 여러 개면 대상은 마지막으로 마우스를 댄 영상, 재생 중인 영상, 크게 보이는 영상 순으로 고른다.
- 다른 도메인에서 임베드한 영상도 조작할 수 있다(예: 블로그에 넣은 YouTube).
- 키를 누르면 영상 위에 "+10s", "볼륨 40%", "⏸" 같은 표시(OSD)를 잠깐 띄운다. 전체화면에서도 보인다.
- 사이트가 위치를 되돌리면 "이 플레이어가 이동을 막고 있음"이라고 알린다.

### 4.2 기능 B — 플레이어 UI 효과 제거 (Clean View)
- 제거 대상:
  - 하단 재생바 뒤 검은 그라데이션과 반투명 배경
  - hover 시 나타나는 컨트롤바, 미리보기 썸네일, 툴팁
- 유지 대상: 자막, 영상에 구워진 레터박스
- 적용 방식 (우선순위 순):
  1. CSS 주입(`display:none` / `background:none`)
  2. hover 이벤트 차단. 프리셋이 지정한 경우만 쓰고, 클릭 동작은 유지한다.
  3. 기본 `controls` 속성 제거 + 다시 붙으면 계속 제거
- 적용 범위 (3계층):
  1. **모든 사이트 공통:** 기본 컨트롤 배경 제거, 영상 위 그라데이션의 배경만 제거
  2. **플레이어 종류별 프리셋:** YouTube, Video.js, JW Player, Plyr, Shaka, MediaElement, Vimeo, Clappr, Flowplayer. 페이지 구조로 감지하므로, 같은 플레이어를 쓰는 처음 보는 사이트에도 자동 적용된다.
  3. **사이트별 오버라이드:** 특정 사이트만 규칙을 추가하거나 뺀다.
- 숨김 대상 선택자는 코드가 아닌 설정 파일에 둔다. 사이트가 업데이트되면 그 파일만 고친다.
- 참고: 컨트롤바를 숨기면 마우스로 조작하던 버튼도 함께 사라진다. 필요하면 사이트별로 기능 B를 끈다.

### 4.3 팝업 (설정 화면)
```
┌─────────────────────────────┐
│ BroCode                     │
│ www.example.com             │
│ 감지: Video.js · 영상 1개      │
├─────────────────────────────┤
│ 이 사이트에서                  │
│  [■] 단축키 강제               │
│  [■] UI 효과 제거              │
├─────────────────────────────┤
│ 이동 간격                      │
│  (●) 1 자동 (영상 길이 기반)     │
│  ( ) 2 고정 15초               │
│  ( ) 3 직접 지정               │
│      앞 [10]초  뒤 [10]초       │
│ 볼륨 단계 [5]%                 │
└─────────────────────────────┘
```
- 새 사이트는 두 기능 모두 **켜짐**으로 시작한다.
- 바꾼 값은 즉시 반영되고 저장된다(Chrome 동기화 저장소).
- 언어는 브라우저 언어를 따른다. 한국어면 한국어, 그 외는 영어다.
- `chrome://` 같은 확장을 실행할 수 없는 페이지에서는 "이 페이지에서는 사용할 수 없음"을 표시한다.

## 5. 기술 개요

| 항목 | 선택 |
|---|---|
| 플랫폼 | Chrome 확장 Manifest V3 |
| 언어 | 바닐라 JavaScript(ES2022), HTML, CSS. 프레임워크·빌드 도구 없음 |
| 코드 규칙 | 주석 없음 |
| 저장 | `chrome.storage.sync` (전역 설정 1개 + 사이트별 키) |
| 다국어 | `chrome.i18n`, `_locales/en`, `_locales/ko` |
| 테스트 | Node 내장 `node:test`(로직), Playwright(확장 로드 후 테스트 페이지) |

**구성**
```
Popup ──설정──▶ chrome.storage ◀──구독── 모든 Content Script
                     │
Service Worker: 기본값 · 프레임별 영상 현황 · 키 전달
                     │
Content Script (모든 프레임)
  ├ 단축키 엔진: 키 가로채기 → 대상 영상 선택 → 컨트롤러 → OSD
  └ UI 제거: 플레이어 감지 → 프리셋/사이트 규칙 적용
                     │ (선택)
Main-world 어댑터: YouTube 등 자체 상태를 가진 플레이어와 동기화
```

**범용성을 확보하는 방법**
- 사이트 이름이 아니라 표준 `<video>` 요소를 직접 제어한다.
- 사이트 스크립트보다 먼저 키를 받는다(페이지 시작 시점에 등록하는 capture 리스너).
- 일반 페이지, shadow DOM 내부, iframe 내부의 영상까지 찾는다.
- UI 제거는 사이트가 아니라 플레이어 라이브러리 단위로 적용한다.

## 6. 구현 단계

| 단계 | 내용 | 완료 기준 |
|---|---|---|
| 1 | 공용 로직(설정, 이동 간격 계산, 호스트 매칭, 키 판정) | 단위 테스트 통과 |
| 2 | 단축키 엔진 + OSD | 테스트 페이지에서 ←→↑↓ Space 동작 |
| 3 | 팝업 + 다국어 + 설정 저장 | 재시작 후에도 값 유지, en/ko 표시 |
| 4 | iframe 간 키 전달 | 다른 도메인 임베드 영상 조작 |
| 5 | UI 효과 제거 (공통 → 프리셋 → 사이트) | 그라데이션/컨트롤 숨김, 자막 유지 |
| 6 | 이동 차단 대응 + YouTube 어댑터 | 차단형 테스트 플레이어 통과 |
| 7 | 실제 사이트 점검 | 아래 목록 확인 |

**실제 사이트 점검 목록:** YouTube, Vimeo, 네이버TV, 치지직, Twitch VOD, 일반 `<video controls>` 페이지, 영상을 임베드한 블로그

## 7. 한계와 확인이 필요한 부분
- **확실한 한계:**
  - 서버가 데이터를 주지 않는 구간과 DRM 영상(Netflix 등)은 이동이 제한될 수 있다.
  - 영상이 없는 다른 도메인 영역(예: 외부 댓글창)에 키보드 입력이 들어가 있으면 키를 받지 못할 수 있다.
- **구현 중 확인할 것:**
  - 사이트가 위치를 되돌리는 방식을 막는 처리가 실제로 효과가 있는지
  - YouTube 플레이어 내부 기능(비공식)이 현재도 쓸 수 있는지
  - 플레이어 프리셋의 클래스명 (실제 페이지에서 확인 후 입력)
  - 브라우저 기본 컨트롤 스타일 규칙(`::-webkit-media-controls-*`)이 현재 Chrome에서 어디까지 적용되는지
  - closed shadow DOM 접근 API가 현재 Chrome에서 동작하는지
  - YouTube에서 볼륨을 직접 바꿀 때 YouTube 화면의 볼륨바와 값이 어긋나는지
  - 주요 플레이어 기본 이동값(YouTube 5초, Netflix 10초 등)

## 8. 결정 기록
- ←→↑↓ Space는 기능 A가 켜져 있으면 항상 BroCode가 처리하고, 나머지 키는 사이트에 맡긴다.
- 새 사이트 기본값은 기능 A와 B 모두 켜짐이다.
- 모드 1 구간표와 볼륨 5% 단계를 쓴다.
- 스페이스바 재생/정지를 필수로 포함한다.
