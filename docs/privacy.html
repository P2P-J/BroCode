개인정보처리방침

시행일 2026년 11월 13일 · 대상 버전 0.1.0 이상

요약 강호의도리는 개인정보를 수집하지 않습니다. 모든 처리는 사용자의 브라우저 안에서만 이루어지며, 개발자나 제3자의 서버로 어떤 데이터도 전송하지 않습니다.

1. 수집하는 정보

없습니다. 이름, 이메일, 계정, 방문 기록, 시청 기록, 입력 내용 등 어떤 개인정보도 수집하지 않습니다. 분석 도구, 광고 SDK, 추적 코드를 사용하지 않습니다.

2. 브라우저에 저장하는 정보

기능을 제공하려고 아래 값을 Chrome이 제공하는 확장 프로그램 저장소에 저장합니다. 이 값은 개발자에게 전송되지 않습니다.

항목저장 위치내용과 보관 기간
전체 설정chrome.storage.sync건너뛰기 간격 모드, 직접 지정한 초, 볼륨 단계. 사용자가 확장을 삭제할 때까지 보관합니다.
사이트별 설정chrome.storage.sync사용자가 팝업에서 스위치를 직접 바꾼 사이트의 호스트 이름(예: www.example.com)과 켜짐/꺼짐 값. 방문한 사이트를 자동으로 기록하지 않습니다.
탭별 영상 상태chrome.storage.session탭 안의 영상 개수, 재생 여부, 감지된 플레이어 종류(예: Video.js), 마지막으로 영상을 조작한 시각. 어떤 영상을 보는지나 페이지 주소는 저장하지 않습니다. 메모리에만 저장되며 탭을 닫거나 브라우저를 종료하면 삭제됩니다.

chrome.storage.sync는 사용자가 Chrome 동기화를 켠 경우 Google 계정을 통해 사용자의 다른 기기와 동기화됩니다. 이 동기화는 Chrome이 처리하며 Google 개인정보처리방침을 따릅니다.

3. 키보드 입력 처리

확장은 동영상 조작을 위해 페이지의 키 입력을 확인합니다. ← → ↑ ↓ Space 다섯 개 키인지만 판단하고, 그 즉시 영상 조작에 사용합니다. 키 입력을 저장하거나 기록하거나 전송하지 않습니다. 입력칸에 글을 쓰는 중이거나 한글을 조합 중일 때는 키를 아예 처리하지 않습니다.

4. 권한을 요청하는 이유

권한이유
storage위 2번의 설정값을 저장합니다.
모든 사이트 접근 (<all_urls>)사용자가 어느 사이트에서 영상을 보든 단축키와 화면 정리 기능을 적용하려면 페이지의 <video> 요소와 플레이어 화면에 접근해야 합니다. 페이지 내용을 읽어서 저장하거나 전송하지 않습니다.

5. 제3자 제공과 판매

데이터를 수집하지 않으므로 제3자에게 제공하거나 판매하는 정보가 없습니다. 확장은 외부 서버와 통신하지 않으며, 원격 코드를 불러와 실행하지 않습니다.

6. 데이터 삭제

Chrome에서 확장을 삭제하면 저장된 설정이 모두 삭제됩니다. 사이트별 설정은 팝업에서 스위치를 원래대로 돌려 바꿀 수 있습니다.

7. 아동의 개인정보

어떤 연령의 사용자로부터도 개인정보를 수집하지 않습니다.

8. 방침의 변경

방침이 바뀌면 이 페이지를 수정하고 시행일을 갱신합니다. 데이터 처리 방식이 달라지는 변경이라면 확장 업데이트 설명에도 함께 알립니다. 변경 이력은 GitHub 커밋 기록에서 확인할 수 있습니다.

9. 문의

개인정보 관련 문의는 GitHub Issues로 남겨 주세요. 소스 코드는 github.com/P2P-J/BroCode에 공개되어 있어 위 내용을 직접 확인할 수 있습니다.

Privacy Policy

Effective November 13, 2026 · Applies to version 0.1.0 and later

In short BroCode does not collect personal data. Everything runs inside your browser, and no data is sent to the developer or to any third party.

1. Information we collect

None. BroCode collects no names, email addresses, accounts, browsing history, watch history or typed content. It contains no analytics, advertising SDKs or tracking code.

2. Information stored in your browser

To work, BroCode keeps the following values in Chrome's extension storage. None of it is sent to the developer.

ItemWhereContents and retention
Global settingschrome.storage.syncSkip interval mode, custom seconds, volume step. Kept until you remove the extension.
Per-site settingschrome.storage.syncThe host name (e.g. www.example.com) and on/off values for sites where you changed a toggle in the popup. Visited sites are not recorded automatically.
Per-tab video statechrome.storage.sessionThe number of videos in the tab, whether one is playing, the detected player type (e.g. Video.js) and when you last controlled a video. What you watch and page addresses are not stored. Held in memory only and cleared when the tab or browser closes.

If you have Chrome Sync turned on, chrome.storage.sync syncs these settings to your other devices through your Google account. That sync is handled by Chrome under the Google Privacy Policy.

3. Keyboard input

BroCode checks key presses on the page in order to control video. It only checks whether a key is one of ← → ↑ ↓ Space and acts on it immediately. Key presses are never stored, logged or transmitted. Keys are not handled at all while you type in an input field or compose text with an IME.

4. Why we request permissions

PermissionReason
storageSaves the settings listed in section 2.
Access to all sites (<all_urls>)To apply hotkeys and the clean view on whichever site you watch video, BroCode needs access to the page's <video> elements and player UI. Page content is never read for storage or transmission.

5. Sharing and sale

Because no data is collected, nothing is shared with or sold to third parties. BroCode makes no network requests and does not load or execute remote code.

6. Deleting your data

Removing the extension from Chrome deletes all stored settings. Per-site settings can be changed back at any time from the popup.

7. Children's privacy

BroCode does not collect personal information from users of any age.

8. Changes to this policy

If this policy changes, this page will be updated along with its effective date. Any change to how data is handled will also be announced in the extension's release notes. The full history is available in the GitHub commit log.

9. Contact

For privacy questions, please open an issue at GitHub Issues. The source code is public at github.com/P2P-J/BroCode, so everything above can be verified.
